# Todo List Git Practice
A simple Todo List web application built with HTML, CSS, and JavaScript. This project allows users to add tasks with due dates and delete tasks from the list.

## Features

- Add a new task
- Add a due date to each task
- Display tasks using CSS Grid
- Delete individual tasks
- Clear the task input after adding a task

## Technologies Used

- HTML
- CSS
- JavaScript

## Git Concepts Practiced

- Initializing and working with a Git repository
- Checking the status of changes with `git status`
- Adding changes using `git add`
- Creating commits using `git commit`
- Creating and working on a separate branch
- Switching between branches
- Merging a completed branch into `main`
- Pushing changes to GitHub
